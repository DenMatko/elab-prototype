# e.Lab lesson prototype

Interactive prototype of a student lesson in e.Lab, a learning platform for a private English school. Made for my product design portfolio.

**Live:** https://denmatko.github.io/elab-prototype/

Open lesson 04 "At the Hotel", go through three short topics with practice questions (instant feedback), then take the final test and see the result. You can review answers, retake the test and unlock the next lesson. Works on desktop and mobile.

Built as a single HTML file, no build step.
